# Banking Data Analysis & Fraud Detection

## Project Overview
This project focuses on analyzing banking data and identifying potentially fraudulent transactions using Microsoft SQL Server.

## Objectives
- Analyze customer account balances.
- Identify customers with multiple active loans.
- Retrieve fraud-flagged transactions.
- Analyze loan distribution across bank branches.
- Detect suspicious high-value transactions.
- Identify transactions performed from different countries within a short time interval.

## SQL Skills
- SELECT, WHERE, ORDER BY
- JOINs
- GROUP BY and HAVING
- Aggregate Functions (SUM, COUNT)
- DATEDIFF
- Data Analysis
- Fraud Detection

## Tools
- Microsoft SQL Server
- SQL

## Project Tasks
1. Top 3 customers by total account balance.
2. Customers with multiple active loans.
3. Fraud-flagged transactions.
4. Total loan amount by branch.
5. Suspicious high-value transactions within one hour.
6. Transactions from different countries within 10 minutes.
